# Korczak Tecnologies — site institucional

Site institucional estático da Korczak Tecnologies, preparado para publicação no domínio raiz.

## Páginas

- `index.html` — apresentação institucional.
- `sobre.html` — história, atuação e princípios.
- `contato.html` — canais de atendimento e comercial.
- `termos.html` — Termos de Uso.
- `privacidade.html` — Política de Privacidade.
- `docs/termos-de-uso.md` — versão Markdown dos Termos de Uso.
- `docs/politica-de-privacidade.md` — versão Markdown da Política de Privacidade.

## Publicação

O workflow em `.github/workflows/pages.yml` publica o conteúdo estático pelo GitHub Pages. Nas configurações do repositório, mantenha Pages com a origem **GitHub Actions**.

O arquivo `CNAME` aponta para `korczaktech.com.br`. O domínio precisa estar configurado no DNS para o GitHub Pages, com HTTPS habilitado após a validação.

## Observação sobre os documentos legais

Os documentos foram transcritos e organizados a partir das seções legais encontradas na fonte do KZTechSite. A política publicada na fonte é resumida e não informa todos os detalhes de tratamento previstos em uma política LGPD completa. Não foram inventados prazos de retenção, fornecedores, cookies, endereço empresarial, CNPJ ou dados de encarregado. Recomenda-se revisão jurídica antes de tratar os textos como documentos legais definitivos.
